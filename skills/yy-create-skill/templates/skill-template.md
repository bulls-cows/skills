# 技能基础模板

本文件提供技能的基础结构模板，供创建新技能时参考。

编写规范详见 `resources/skill-guide.md`。

完整示例详见 `examples/output.md`。

## 模板结构

```markdown
---
name: 技能名称
description: 简要描述这个技能的功能和使用场景
---

# 技能名称

## 描述

**必须包含此章节**。用 1-2 句话描述技能的核心作用，帮助 AI 理解技能用途。

## 使用场景

描述触发这个技能的条件，包括应该触发和不应触发的场景。

## 指令

清晰的分步说明，告诉智能体具体怎么做。最后一步描述输出格式。

## 示例 (可选)

输入/输出示例，展示预期效果。

## 相关资源 (可选)

列出本技能包含的辅助资源文件，如示例、模板、参考文档等。
```
