# 技能基础模板

本文件提供技能的基础结构模板，供创建新技能时参考。

编写规范详见 `resources/skill-guide.md`。

完整示例详见 `examples/output.md`。

## 模板结构

```markdown
---
name: 技能名称
description: >
  <动词引导的动作>. <何时用 / 何时不用>.
---

# 技能名称

## 描述

**必须包含此章节**。用 1-2 句话描述技能的核心作用，帮助 AI 理解技能用途。

## 使用场景

描述触发这个技能的条件，包括应该触发和不应触发的场景。每条都必须紧贴技能本质，避免写"正确的废话"，避免引用其他技能名。

- 用户提到[典型触发场景 1]
- 用户需要[典型触发场景 2]

不应触发：

- 用户要求[功能相邻的另一类操作]
- 用户要求[同一对象的不同操作 / 同一动词的不同对象]

> 编写要点（写完后逐条自查，最终模板中删除本提示）：
>
> - 自问"不写这一条，AI 真的会误触发本技能吗"——答案为否就删掉
> - 排除条件优先来自：功能相邻 / 同一对象的不同操作 / 同一动词的不同对象 / 近义请求
> - **不得引用其他技能名**（如"使用 yy-xxx"、"参见 X 技能"）；只描述行为差异

## 指令

### 步骤 1. 识别任务目标

说明如何判断用户意图、补齐必要信息，或确定本技能的适用边界。

### 步骤 2. 执行核心流程

按顺序描述主要操作；如存在条件分支，使用明确的决策分支格式。

**决策分支**：

- **条件 A**：执行行为 A
- **条件 B**：执行行为 B

### 步骤 3. 输出结果

说明最终必须输出的结果结构和关键字段。

## 安全边界

如果技能涉及敏感操作、会改变现有状态，或可能触发高影响动作，列出禁止主动执行的行为；无此类风险时可省略本章节。

## 相关资源

列出本技能包含的辅助资源文件，如示例、模板、参考文档等。
```
