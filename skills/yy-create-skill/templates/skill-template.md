# 技能基础模板

本文件提供技能的基础结构模板，供创建新技能时参考。

编写规范详见 `resources/skill-guide.md`。

完整示例详见 `examples/output.md`。

## 模板结构

```markdown
---
name: 技能名称
description: >
  <动词引导的动作>. <何时用 / 何时不用>.
---

# 技能名称

## 描述

**必须包含此章节**。用 1-2 句话描述技能的核心作用，帮助 AI 理解技能用途。

## 使用场景

描述触发这个技能的条件，包括应该触发和不应触发的场景。

## 指令

### 步骤 1. 识别任务目标

说明如何判断用户意图、补齐必要信息，或确定本技能的适用边界。

### 步骤 2. 执行核心流程

按顺序描述主要操作；如存在条件分支，使用明确的决策分支格式。

### 步骤 3. 输出结果

说明最终必须输出的结果结构和关键字段。

## 相关资源

列出本技能包含的辅助资源文件，如示例、模板、参考文档等。
```
