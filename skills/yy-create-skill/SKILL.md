# yy-create-skill

## 描述

帮助用户创建或更新符合规范的 Skill 技能文件，包含完整的目录结构、YAML 元数据和可执行的指令步骤。

Skill 本质上是"可按需加载的任务说明书"，用于复用复杂流程。关键特点：

1. **自动发现**：会被自动发现，只在相关时加载，避免上下文膨胀
2. **精确触发**：description 要精确，避免误触发
3. **明确边界**：必须有使用场景（触发条件和不应触发场景）
4. **指令清晰**：步骤明确，最后一步描述输出格式

## 使用场景

- 用户想要创建新技能
- 用户想要更新现有技能
- 用户需要把某个工作流程标准化为技能
- 用户想把某个功能打包成可复用的技能

不应触发：

- 用户只是询问技能是什么
- 用户要求创建普通文件
- 用户要求创建规则文件（应使用 yy-create-rule）

## 指令

### 1. 捕获意图

理解用户的需求，确定是**创建新技能**还是**更新现有技能**。

- 如果用户需求明确（如"创建一个格式化代码的技能"），直接进入步骤 2，不再逐一询问
- 如果用户需求模糊（如"帮我搞个技能"），使用以下引导问题补充信息：
  1. 这个技能应该让 AI 助手能做什么？
  2. 何时应触发这个技能？
- 对于**更新现有技能**，先读取现有 SKILL.md 内容，确认用户要更新的部分

### 2. 确定技能目录

- **创建新技能**：使用小写、短横线分隔的命名方式，遵循以下原则：
  - **名词使用单数形式**：如 `create-skill` 而非 `create-skills`
  - **优先动宾结构**：如 `create-skill`、`read-pdf`、`lint-code` 而非 `skills-creator`、`pdf-reader`
- **更新现有技能**：直接使用现有技能目录

命名规范详见 `resources/skill-guide.md`。

### 3. 确定输出目录

- 如果用户指定了目录，则在用户指定目录下生成技能
- 如果用户未指定目录，按以下优先级检测：
  1. 项目中已有的技能目录（如 `skills/`、`.agents/skills/`）
  2. 无已有目录时，在项目根目录创建 `skills/` 目录

### 4. 编写 SKILL.md

SKILL.md 的编写原则和模板请参考 `templates/skill-template.md`。

#### 默认策略

- description 默认使用 `>` 折叠式语法（禁止行内写法）
- 默认只生成 SKILL.md，不自动创建 examples/、templates/、resources/ 目录
- 仅在以下条件满足时才创建辅助目录：
  - **templates/**：需要生成的模板内容超过 20 行（不含空行和代码块标记行）
  - **resources/**：需要独立的参考文档，且内容不适合放在 SKILL.md 正文
  - **examples/**：用户明确要求提供示例

#### description 编写约束

description 只用于给 AI 判断是否触发技能：

- 只写技能用途和触发场景，不写实现方式
- 保持简短，避免堆叠步骤、规则、例外和实现细节
- 具体约束写在正文，如使用场景、指令、示例
- 如果 description 已经开始解释"怎么做"，通常说明写宽了

#### YAML frontmatter 字段约束

- 只允许 `name` 和 `description` 两个字段
- 禁止添加其他字段（如 `version`、`author`、`tags` 等）

### 5. 创建目录结构

根据步骤 4 的判断结果创建目录。

**创建新技能**的目录结构规范详见 `resources/skill-guide.md`。

**更新现有技能**时：读取现有目录结构，只修改 SKILL.md 或用户指定的部分，不删除已有辅助文件。

### 6. 验收

创建或更新技能后，按以下清单检查：

1. 包含 `## 描述` 章节，用 1-2 句话说明技能核心作用
2. description 只写用途和触发场景，不含实现细节
3. 使用场景明确（触发条件和不应触发场景）
4. 指令步骤完整可执行，最后一步描述输出格式
5. YAML frontmatter 只包含 `name` 和 `description` 字段，使用 `>` 折叠式语法
6. 文件命名符合规范（kebab-case）
7. 使用中文描述
8. 代码示例包含语言标签

详细验收清单见 `resources/skill-guide.md`。

### 7. 输出结果

输出以下内容：

1. **创建/更新结果**：技能名称和操作类型
2. **目录结构**：生成的文件树
3. **SKILL.md 内容摘要**：description 文本、指令步骤概要

## 相关资源

本技能包含以下辅助资源：

- `examples/input.md`：输入示例，展示用户如何请求创建技能
- `examples/output.md`：输出示例，展示创建技能后的预期结果
- `templates/skill-template.md`：基础技能模板
- `resources/skill-guide.md`：技能编写完整指南（命名规范、YAML 语法、章节编写原则、交互设计、验收清单）
