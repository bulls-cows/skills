# 敏感文件命名特征清单

`yy-commit` 技能在步骤 4 展示暂存文件时，依据本清单识别**新增**敏感文件并标注 ⚠️ 提示；**已追踪文件的修改不重复提醒**。

## 命名特征

- **凭据与密钥类**：`credentials.*`、`secrets.*`、`*.key`、`*.pem`、`*.pfx`、`*.p12`
- **含敏感命名的文件**：文件名包含 `password`、`token`、`secret`、`apikey` 等关键词
- **环境变量文件**：`.env`、`.env.*`（仅在文件未被 `.gitignore` 忽略时才会出现在改动列表中，提示仍有价值）

## 处理规则

- 仅对新增文件标注 ⚠️ 提示
- 命中快速提交模式时，敏感文件强制阻塞流程，回退到常规确认
- 用户须明确豁免该文件或将其从暂存列表移除后才能继续提交

## 排除来源权威性

- 以 `.gitignore` 为权威排除来源，不在其之上叠加二级黑名单
- 未被忽略的文件视为允许提交，仅对新增敏感命名特征文件给出展示警告
