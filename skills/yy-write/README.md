# yy-write

## 技能来源

本技能基于 [khazix-writer](https://github.com/KKKKhazix/khazix-skills/tree/main/khazix-writer) 技能进行适配和汉化。

khazix-writer 是数字生命卡兹克（Khazix）的个人写作风格技能，账号全称「数字生命卡兹克」，是一个以「激发大家对AI的好奇」为使命的公众号。

## 主要改动

1. **去除了个人品牌标识**：移除了卡兹克账号特有的个人信息和署名
2. **保留了核心写作方法论**：保留了有见识的普通人的写作风格指导
3. **扩充了参考资源**：添加了详细的风格示例库和内容方法论文档
4. **优化了结构**：更适合作为通用技能被其他用户使用

## 核心特点

本技能强调"真人感"的写作风格：

- 像跟朋友聊天，不像写报告
- 讲人话，拥抱不完美
- 真诚是唯一的捷径
- 亲自下场做调查实验
