# yy-run-skills

## 描述

按顺序串行调用多个技能，支持多种分隔符输入，逐个执行直到全部完成或某个失败。

## 使用场景

- 用户需要按顺序执行多个技能
- 用户输入 `/yy-run-skills skill1 skill2`
- 用户提到"串行执行"、"依次执行"、"按顺序执行技能"

不应触发：

- 用户只需要执行单个技能
- 用户要求并行执行多个技能
- 用户只是询问有哪些技能

## 指令

### 步骤 1. 解析技能列表

1. 读取用户输入的技能列表字符串
2. 将所有分隔符统一替换为空格（支持：空格、英文逗号 `,`、中文逗号 `，`、中文顿号 `、`）
3. 按空格分割并过滤空白项，得到技能名称数组

**决策分支**：

- **有效技能名称数组非空**：进入步骤 2
- **数组为空**：提示用户提供至少一个技能名称，退出执行

### 步骤 2. 串行执行技能

按顺序逐个执行：

1. 使用 Skill tool 调用当前技能
2. 等待技能执行完成
3. 记录执行结果（成功/失败）

**决策分支**：

- **执行成功**：继续执行下一个技能
- **技能不存在**：记录为失败，展示错误信息，询问用户是否继续执行剩余技能
- **执行失败**：展示错误信息，询问用户是否继续执行剩余技能
  - **用户选择继续**：跳过当前失败技能，执行下一个
  - **用户选择停止**：终止执行，进入步骤 3

### 步骤 3. 输出执行摘要

所有技能执行完成后，输出结果：

```text
技能执行完成

执行摘要：
总技能数：{总数}
成功：{成功数}
失败：{失败数}

详细结果：
1. {技能名} - 成功
2. {技能名} - 失败：{错误信息}
```
