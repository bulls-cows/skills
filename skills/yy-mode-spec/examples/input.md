# 输入示例

本文档展示用户请求制定规格的典型输入示例。

## 示例 1：简单需求

```text
/yy-mode-spec
为用户列表页面添加批量删除功能
```

## 示例 2：复杂需求

```text
/yy-mode-spec
创建实时通知系统，支持 WebSocket 推送和消息持久化
```

## 示例 3：指定目录

```text
/yy-mode-spec --tool-dir .agents --requirement-dir 用户认证系统
创建基于 JWT 的用户认证功能
```

## 示例 4：确认执行

```text
确认执行
```

## 示例 5：要求调整规格

```text
API 规格中缺少错误码定义，请补充
```

## 示例 6：补充技术细节

```text
数据库选型需要考虑 PostgreSQL 和 MySQL 的对比，请补充技术选型分析
```
