# 验证清单模板

本文档提供验证清单的基础结构模板。

```markdown
# [功能名称] 验证清单

> 本文档是质量验证检查表，与 [spec.md](./spec.md)（规格说明书）、[tasks.md](./tasks.md)（任务分解）配合使用。所有任务完成后，逐项检查通过即可交付。

## 实施前检查

- [ ] 代码评审通过
- [ ] 测试用例编写完成
- [ ] 开发环境就绪

## 实施中检查

- [ ] 每个任务完成后更新任务状态
- [ ] 遇到阻塞及时升级

## 实施后验证

- [ ] 所有任务完成
- [ ] 单元测试覆盖率 > 70%
- [ ] API 文档已更新
- [ ] 集成测试通过

## 质量门禁

- [ ] lint 检查通过
- [ ] TypeScript 编译无错误
- [ ] 安全扫描通过
```
