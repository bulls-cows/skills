# yy-resume

## 描述

生成面向前端/后端/全栈程序员的专业 HTML 简历，包含技能栈、项目经验、GitHub/LinkedIn 链接等字段，支持 A4 纸张完美打印。

## 使用场景

- 用户需要创建或更新程序员简历
- 用户需要生成可打印的 HTML 格式简历
- 用户需要包含技术栈、项目经验等专业内容的简历

不应触发：

- 用户只是询问简历格式
- 用户需要非程序员类简历
- 用户只需要简单的文本简历

## 指令

### 步骤 1. 收集简历信息

向用户收集以下简历信息：

1. **基本信息**：姓名、职位、联系方式（电话、邮箱）、所在城市
2. **社交链接**：GitHub、LinkedIn、个人博客等（可选）
3. **个人简介**：1-2 段简短的职业介绍
4. **技能栈**：按类别（前端、后端、数据库、工具等）列出技术技能
5. **工作经验**：公司名称、职位、时间区间、工作描述（包含技术亮点）
6. **项目经验**：项目名称、角色、技术栈、项目描述、成果
7. **教育背景**：学校、专业、时间区间
8. **其他**：证书、开源贡献等（可选）

### 步骤 2. 生成 HTML 简历

使用 `templates/resume-template.html` 作为模板，将收集到的信息填充到模板中，生成完整的 HTML 文件。

生成的 HTML 必须满足以下 A4 分页打印约束：

1. **章节不被截断**：每个 `section` 使用 `break-inside: avoid`，避免同一章节被分页截断
2. **条目不被截断**：每个经验/项目/教育条目使用 `break-inside: avoid`，避免同一公司或项目的标题与描述被拆到两页
3. **标题不孤悬**：`h2` 使用 `break-after: avoid`，避免章节标题在页末而内容在下一页
4. **技能类别不被截断**：每个 `.skills-category` 使用 `break-inside: avoid`，避免技能类别名称与技能标签被拆开

### 步骤 3. 输出结果

将生成的 HTML 文件保存到用户指定的位置，或直接输出 HTML 内容，并说明：

- 如何在浏览器中打开预览
- 如何使用浏览器的打印功能（Ctrl+P / Cmd+P）选择 A4 纸张进行打印
- 建议使用"打印到 PDF"功能保存为 PDF 格式
