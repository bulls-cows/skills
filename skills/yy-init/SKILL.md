# yy-init

## 描述

初始化或更新项目的 AGENTS.md 文档，确保 AI 助手能够理解项目的规范、范围和结构，并主动应用体系化思考方式。

## 使用场景

- 用户提到"初始化项目"、"初始化 AGENTS.md"
- 用户提到"创建 AGENTS.md"、"生成项目规范文档"
- 用户想要为项目添加 AI 助手指导文档
- 用户提到"项目规范"、"AI 理解项目"

不应触发：

- 用户只是查看 AGENTS.md 内容
- 用户要求创建普通文档（如 README.md）
- 用户要求创建规则文件（应使用 yy-create-rule）

## 指令

### 1. 检查 AGENTS.md 状态

检查项目根目录下是否存在 `AGENTS.md` 文件：

- **不存在**：提示用户将创建新文件，继续执行步骤 2
- **存在**：读取现有内容
  - **默认策略**：补充缺失部分，保留现有内容
  - **用户明确要求"完全重写"**：覆盖生成

### 2. 收集项目信息

分析项目结构，自动识别以下信息：

- **范围**：识别主要编程语言、允许修改目录（如 src/、tests/）、禁止修改目录（如 dist/、node_modules/）
- **改动检查**：检测 package.json 中的 lint、test 脚本
- **项目结构**：分析目录结构，最多 4 级

**决策分支**：

- **能自动识别**：直接使用识别结果
- **无法自动识别**：询问用户核心问题：
  1. 项目主要使用什么编程语言？
  2. 有哪些目录禁止修改？

### 3. 生成 AGENTS.md

参考 `templates/agents-minimal-template.md` 的结构，根据收集的项目信息生成 AGENTS.md 文档。

**必须包含的章节**：

1. 范围
2. 改动检查
3. 交付格式
4. 项目结构
5. AI 思考方式
6. 路径格式规范
7. 规则引用（如有规则目录）

### 4. 保存并输出结果

使用 Write 工具保存文件，输出结果：

```text
✓ 已创建/更新 AGENTS.md
✓ 文件路径: [项目根目录]/AGENTS.md
✓ 包含章节: 范围, 改动检查, 交付格式, 项目结构, AI 思考方式, 路径格式规范, 规则引用
```

## 注意事项

- 使用正斜杠作为路径分隔符，路径包含空格时使用引号包裹，以确保跨平台兼容性和正确解析
- 保持 AGENTS.md 内容精简，具体规则应存放到 `.agents/rules/` 目录
- 若存在规则目录（如 `.agents/rules/`、`.claude/rules/`），在 AGENTS.md 中添加规则引用
- 项目结构说明最多 4 级，重点说明各目录和文件的作用
- 使用中文编写内容（除非项目文档是英文）
- 更新时默认保留现有内容，仅补充缺失部分
- **AI 思考方式章节**：按"行动前思考→克制与精简→验证与比对"三个认知阶段组织，涵盖假设显式化、决策点显式化、简单优先、精确修改、显式分级筛选、目标驱动执行、交叉比对式矛盾定位、逆向逻辑验证
