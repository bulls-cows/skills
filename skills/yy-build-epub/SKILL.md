# yy-build-epub

## 描述

使用随附 Python 构建器转换已有 Markdown，不调用 AI 写正文。默认同时生成 EPUB 3、单文件全书预览 HTML、分章预览 ZIP 和检查报告；PDF 是用户要求时才执行的独立步骤。工具可从本技能复制到授权工作目录使用，不依赖固定安装路径。

## 使用场景

- 用户已有 Markdown 章节，要求构建或重新生成 EPUB 电子书。
- 用户需要检查 EPUB 结构，或同时生成全书 HTML 预览及可选 PDF。

不应触发：

- 用户要求分析项目源码、编写或扩写书籍正文。
- 用户要求把任意 PDF、Word、扫描图片或网页转换为 EPUB；随附工具只接收 Markdown 书稿。

## 指令

### 步骤 1. 确定输入、产物和覆盖权限

确认现有 book.json 或书稿目录、章节顺序、书名、语言、封面与输出位置。**输入已完整**：直接使用；**缺少配置**：依据实际文件创建配置，只询问会改变章节顺序或书名的缺失选择；**缺正文**：报告缺少的章节，不补写内容。

- **构建**：生成默认四个产物。
- **仅检查已有 EPUB**：运行 check，不创建配置、复制工具或重新构建。
- **用户还要求 PDF**：构建后执行独立 HTML 转 PDF；没有浏览器时报告 PDF 步骤未完成，不影响已完成的 EPUB。

既有产物默认不覆盖。用户明确授权重建时才加 `--force`；即使授权也不能覆盖输入。书稿仍有草稿或缺章时，明确是阶段版，不声称全书已完成。

### 步骤 2. 准备可执行工具

先读取 [resources/builder-usage.md](resources/builder-usage.md)。本技能的 `scripts/` 包含构建器、主题、依赖和测试；可以直接运行，也可复制整个 scripts/ 到用户授权的工具目录。检查目标是否已有相同职责工具，存在则优先使用并核对接口，禁止盲目覆盖。

复制时保留 `themes/` 与脚本的相对位置，不复制虚拟环境、缓存或生成产物。不要修改技能随附脚本来适配某本书；书籍差异写进配置。Python-Markdown 依赖安装在隔离虚拟环境中，不改全局 Python 环境；执行安装前遵守当前环境权限要求。

### 步骤 3. 核对配置与 Markdown

采用以下配置格式，字段与随附工具一致：

```json
{
  "title": "实际书名",
  "language": "zh-CN",
  "theme": "eink",
  "output": "output/book.epub",
  "chapters": [{"file": "chapters/01-intro.md", "title": "第一章：介绍"}]
}
```

`authors`、`cover`、`identifier` 可选；章节顺序使用数组顺序。配置路径相对 book.json，图片和章节链接相对当前 Markdown。参考页数不写入配置，构建器不接受或保证固定页数。

核对本地图片、稳定锚点及跨章链接；源码路径作为普通文本保留，不做未打包源码附件链接。只修复用户授权的格式、资源或链接问题，不借构建任务扩写或修改正文语义。具体支持语法和拒绝内容见使用说明。

### 步骤 4. 构建、检查与可选 PDF

按使用说明中的命令安装依赖、构建并检查。路径从当前环境取得，不能照抄固定机器路径。核心命令为：

```text
<python> <tool-dir>/book_builder.py build <book.json>
<python> <tool-dir>/book_builder.py check <output.epub>
<python> <tool-dir>/html_to_pdf.py <output.preview.html>
```

第三条仅在用户要求 PDF 时运行；可用浏览器、参数、失败保护与信任边界见使用说明。不要为 PDF 自动安装浏览器、降低浏览器安全选项或执行未知 HTML。

- **命令成功**：核对实际产物存在，读取报告；具备浏览器时可检查 HTML，未实检则如实说明。
- **解析、图片或链接错误**：定位配置/书稿的具体问题，授权范围内修复后重试；没有修复权限时报告阻塞点。
- **输出已存在**：没有覆盖授权则询问或使用已授权的新输出位置，不静默添加 force。
- **PDF 失败**：保留 EPUB 与原 PDF，单独报告浏览器、超时或输出错误，不将部分成功报成全部完成。

### 步骤 5. 验收与交付

报告实际生成的 EPUB、HTML、ZIP、JSON，以及可选 PDF 路径；说明执行命令、检查结果、书稿是否完整、覆盖操作与未验证项。结构检查通过不等于 EPUBCheck 或设备实测，不声称没有代码溢出或固定页数。

```text
构建状态：成功 / 部分成功 / 失败，是否为阶段版
产物：实际文件路径
验证：命令、退出结果与报告范围
未验证：EPUBCheck、目标设备、字体/代码/表格排版等实际缺口
下一步：打开 HTML 或导入设备检查；可选 PDF 的状态
```

## 安全边界

- 不撰写正文、不修改项目源码、不自动提交或发布书籍。
- 仅处理可信本地书稿。构建器的 HTML/SVG 限制不是完整安全审计；PDF 浏览器会渲染 HTML，并非隔离未知内容的沙箱。
- 不直接编辑生成的 EPUB/HTML 修正文稿；回到 Markdown、配置或主题真源并重建。
- 四个构建产物逐文件替换，不保证跨文件事务；转换失败的基本保护不能替代备份与人工验收。
