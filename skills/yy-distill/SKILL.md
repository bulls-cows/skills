# yy-distill

从用户指定的内容中分析并提炼核心特质。

## 描述

从用户指定的内容中分析并提炼核心性格特质，构建思维操作系统。

## 使用场景

- 用户想要分析自己的风格
- 用户想要提炼个人特质
- 用户想要生成个人画像
- 用户想要理解他人的思维风格

不应触发：

- 用户只是查看内容
- 用户要求统计数量
- 用户要求分析其他人的内容（除非提供了该人的内容）

## 指令

### 1. 确定分析来源

**必须要求用户提供分析来源**。

如果用户未提供来源，询问用户希望分析什么内容。

可接受的内容形式：

- 文件路径（单个文件或目录）
- 文本内容（直接粘贴）
- URL（博客、文章等）
- 代码仓库

### 2. 多维度信息采集

从以下六个维度分析内容：

#### 2.1 内容类型分析

识别主要内容类型及其比例：

- 主要内容形式是什么？
- 类型分布如何？
- 关注重点是什么？
- 表达偏好是什么？

#### 2.2 高频概念分析

识别反复出现的概念：

- 核心关注点是什么？
- 价值取向如何？
- 思维习惯是什么？
- 反复出现的动词和名词有哪些？

#### 2.3 决策痕迹分析

识别选择、取舍、判断的痕迹：

- 决策逻辑是什么？
- 优先级如何排序？
- 权衡方式是什么？
- 风险态度如何？

#### 2.4 表达方式分析

分析语言风格和结构：

- 句式偏好是什么？（长句/短句、疑问/陈述）
- 词汇特征有哪些？（高频词、专属术语、禁忌词）
- 节奏感如何？（先结论还是先铺垫、转折方式）
- 确定性表达如何？（「我不确定」型还是「很明显」型）

#### 2.5 互动模式分析

分析与他人/内容的互动：

- 沟通风格是什么？
- 反馈方式如何？
- 开放性如何？

#### 2.6 时间线分析

分析内容的时间分布：

- 持续性如何？
- 变化趋势是什么？
- 成长轨迹如何？

### 3. 三重验证机制

对每个候选特质进行三重验证：

#### 验证1: 跨域复现

特质是否在多个不同场景/类型的内容中出现？

- 是 → 继续验证
- 否 → 降级为观察，不作为核心特质

#### 验证2: 有生成力

能否推断在面对新情况时的可能反应？

- 能 → 继续验证
- 不能 → 降级为描述，不作为预测性特质

#### 验证3: 有排他性

是否不是所有人都会这样？是否体现独特性？

- 是 → 确认为核心特质
- 否 → 降级为共性，不作为个人特质

**验证结果处理**：

- 三重通过 → 核心特质
- 两重通过 → 次要特质
- 一重通过 → 观察记录
- 零重通过 → 不纳入

### 4. 提炼特质

从人的性格特质角度提炼，而非操作层面：

- **应该**：使用"追求本质""系统化思考""长期主义"等性格特质
- **不要**：使用"DRY 原则践行者""结构化思维"等操作描述

提炼原则：

1. 每条特质用一句话概括，包含特质名称和具体表现
2. 基于内容证据，不做主观臆断
3. 从"为什么这么做"的角度理解，而非"做了什么"

#### 避免套模板（重要）

**严禁照搬示例中的特质名称和描述**。示例仅供参考输出格式，特质内容必须从实际分析数据中提炼。

错误做法：

- 直接使用示例中的"追求本质""系统化思考""长期主义"等特质名称
- 套用示例中的证据描述
- 输出与示例高度相似的特质组合

正确做法：

- 从实际数据中识别独特的行为模式
- 用自己的语言命名和描述特质
- 确保证据来自分析内容，而非示例
- 如果分析结果与示例相似，应反思是否真正基于数据提炼

**自检方法**：输出前对照示例，检查特质名称是否雷同。如果超过一半的特质名称与示例相同，需要重新分析数据。

#### 隐私保护原则（重要）

输出结果必须遵循以下隐私保护原则：

1. **不引用原文**：不要直接引用或复述输入内容中的具体文本
2. **不暴露细节**：不要提及具体的文件名、代码片段、提交信息、人名、具体数值等
3. **抽象概括**：将具体行为抽象为一般性描述
4. **证据抽象化**：证据部分使用抽象化后的描述，而非原始内容

错误示例（暴露隐私）：

- "大量'移除'、'简化'、'删除'类提交"
- "如'移除未使用的导入'、'简化 lint 脚本逻辑'"
- "提交类型分布：feat (852)、refactor (549)"
- "主要贡献者：张三 (57%)、李四 (39%)"

正确示例（抽象概括）：

- "频繁进行代码简化相关的操作"
- "倾向于移除冗余代码和配置"
- "提交类型以功能开发和重构为主"
- "由少数核心贡献者主导"

### 5. 输出特质分析报告

按照以下结构输出分析结果：

#### 输出格式结构

- **数据概览**（可选）：分析来源的基本统计信息
- **核心特质**（必选）：含定义、证据、三重验证结果
- **次要特质**（可选）：未通过完整验证但有价值的观察
- **特质关联图谱**（可选）：特质之间的因果关系
- **行为预测**（可选）：基于特质预测在新场景下的反应
- **总结**（必选）：特质组合的整体概括
- **说明**（必选）：隐私说明和局限性分析

#### 特质描述格式

每个特质包含以下要素：

- **定义**：一句话概括特质含义
- **证据**：从分析内容中提取的抽象化证据（2-4 条）
- **验证**：三重验证结果（跨域复现、有生成力、有排他性）
