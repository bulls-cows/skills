# yy-distill

## 描述

从用户指定的内容中分析并提炼能力模型，涵盖感知能力、学习能力、推理能力和决策能力四个维度。

## 使用场景

- 用户想要分析感知模式和信息获取方式
- 用户想要识别学习路径和知识迁移方式
- 用户想要挖掘推理逻辑和论证方式
- 用户想要理解决策习惯和判断方式

不应触发：

- 用户只是查看内容
- 用户要求统计数量
- 用户要求分析其他人的内容（除非提供了该人的内容）
- 用户仅需要分析性格特质而非能力模型

## 指令

### 1. 确定分析来源

**必须要求用户提供分析来源**。

如果用户未提供来源，询问用户希望分析什么内容。

可接受的内容形式：

- 文件路径（单个文件或目录）
- 文本内容（直接粘贴）
- URL（博客、文章等）
- 代码仓库

### 2. 四维能力信息采集

从以下四个维度分析能力模型：

#### 2.1 感知能力

分析信息获取和模式识别的方式：

- 信息获取偏好：主动探索还是被动接收？关注全局还是细节？
- 模式识别：能否快速发现规律和异常？
- 信号筛选：如何从噪声中提取关键信息？
- 跨域感知：能否识别不同领域间的相似性？

#### 2.2 学习能力

分析知识吸收和迁移的方式：

- 学习路径：自上而下还是自下而上？先框架还是先实例？
- 知识迁移：如何将已有知识应用到新领域？
- 反馈整合：如何从结果中提取经验并调整？
- 抽象提取：能否从具体实例中提炼通用模式？

#### 2.3 推理能力

分析逻辑推导和论证的方式：

- 推理路径：演绎、归纳、类比还是混合？
- 假设构建：如何形成和验证假设？
- 因果分析：如何建立因果关系和排除干扰？
- 逻辑严密性：论证的完整性和一致性如何？

#### 2.4 决策能力

分析判断和选择的方式：

- 决策依据：优先考虑什么因素？
- 权衡取舍：如何在冲突目标间取舍？
- 风险评估：如何评估和应对不确定性？
- 验证闭环：如何确认决策的正确性？

### 3. 三重验证机制

对每个候选能力进行三重验证：

#### 验证1: 跨域一致性

能力是否在不同场景下稳定体现？

- 是 → 继续验证
- 否 → 降级为观察，不作为核心能力

#### 验证2: 有预测力

能否推断在新场景下的能力表现？

- 能 → 继续验证
- 不能 → 降级为描述，不作为预测性能力

#### 验证3: 有独特性

是否体现独特的能力特征而非通用做法？

- 是 → 确认为核心能力
- 否 → 降级为共性，不作为独特能力

**验证结果处理**：

- 三重通过 → 核心能力
- 两重通过 → 次要能力
- 一重通过 → 观察记录
- 零重通过 → 不纳入

### 4. 提炼能力模型

从能力角度提炼，而非操作层面：

- **应该**：使用"主动探索未知领域""通过类比迁移知识""自上而下构建认知框架"等能力描述
- **不要**：使用"DRY 原则践行者""代码写得好"等操作或结果描述

提炼原则：

1. 每条能力用一句话概括，包含名称和具体表现
2. 基于内容证据，不做主观臆断
3. 从"如何感知/学习/推理/决策"的角度理解，而非"做了什么"

#### 避免套模板（重要）

**严禁照搬示例中的能力名称和描述**。示例仅供参考输出格式，能力内容必须从实际分析数据中提炼。

错误做法：

- 直接使用示例中的能力名称
- 套用示例中的证据描述
- 输出与示例高度相似的能力组合

正确做法：

- 从实际数据中识别独特的能力特征
- 用自己的语言命名和描述能力
- 确保证据来自分析内容，而非示例
- 如果分析结果与示例相似，应反思是否真正基于数据提炼

**自检方法**：输出前对照示例，检查能力名称是否雷同。如果超过一半的能力名称与示例相同，需要重新分析数据。

#### 隐私保护原则（重要）

输出结果必须遵循以下隐私保护原则：

1. **不引用原文**：不要直接引用或复述输入内容中的具体文本
2. **不暴露细节**：不要提及具体的文件名、代码片段、提交信息、人名、具体数值等
3. **抽象概括**：将具体行为抽象为一般性描述
4. **证据抽象化**：证据部分使用抽象化后的描述，而非原始内容

错误示例（暴露隐私）：

- "大量'移除'、'简化'、'删除'类提交"
- "如'移除未使用的导入'、'简化 lint 脚本逻辑'"
- "提交类型分布：feat (852)、refactor (549)"
- "主要贡献者：张三 (57%)、李四 (39%)"

正确示例（抽象概括）：

- "频繁进行代码简化相关的操作"
- "倾向于移除冗余代码和配置"
- "提交类型以功能开发和重构为主"
- "由少数核心贡献者主导"

### 5. 输出能力模型分析报告

按照以下结构输出分析结果：

#### 输出格式结构

- **数据概览**（可选）：分析来源的基本统计信息
- **核心能力**（必选）：按感知、学习、推理、决策四维度分组，含定义、证据、三重验证结果
- **次要能力**（可选）：未通过完整验证但有价值的观察
- **能力关联图谱**（可选）：能力之间的因果关系
- **能力路径预测**（可选）：基于能力模型预测在新场景下的行为路径
- **总结**（必选）：能力模型的整体概括
- **说明**（必选）：隐私说明和局限性分析

#### 能力描述格式

每个能力包含以下要素：

- **所属维度**：感知 / 学习 / 推理 / 决策
- **定义**：一句话概括能力含义
- **证据**：从分析内容中提取的抽象化证据（2-4 条）
- **验证**：三重验证结果（跨域一致性、有预测力、有独特性）
