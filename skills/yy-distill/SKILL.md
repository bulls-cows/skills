# yy-distill

## 描述

从用户指定的内容中分析并提炼能力模型，用于指导 AI agent 的通用行为/底层能力。涵盖感知能力、学习能力、推理能力、决策能力和其他能力五个维度。

**核心约束**：生成的能力描述必须是通用行为模式（能跨项目、跨 AI 模型复用）、具体可执行（能直接指导 AI agent 的决策和行为）、底层能力（而非特定项目的技能或操作）。

## 使用场景

- 用户想要从指定内容中提炼能力模型
- 用户想要分析 AI agent 的思维模式和行为特征

不应触发：

- 用户只是查看或总结内容，不涉及能力提炼
- 用户要求分析性格特质而非能力模型
- 用户要求统计数量或排序

## 指令

### 步骤 1. 确定分析来源

**必须要求用户提供分析来源**。

**决策分支**：

- **用户提供了来源**：直接进入步骤 2
- **用户未提供来源**：询问用户希望分析什么内容，等待用户回复后再进入步骤 2

可接受的内容形式：

- 文件路径（单个文件或目录）
- 文本内容（直接粘贴）
- URL（博客、文章等）
- 代码仓库

### 步骤 2. 五维能力分析

从以下五个维度分析能力模型，每个维度关注其核心分析要点：

- **感知能力**：信息获取方式（主动/被动）、理解倾向（全局/细节）、模式识别、跨域感知
- **学习能力**：知识提取路径（自上而下/自下而上）、模式发现、知识迁移、持续优化
- **推理能力**：推理方式（演绎/归纳/类比/混合）、知识推断、假设构建、因果分析
- **决策能力**：决策依据（如何综合前三维）、方案选择、风险评估、行动执行
- **其他能力**：无法归入前四维的能力特征、跨维能力、独特行为模式

### 步骤 3. 验证与提炼

对每个候选能力依次执行：

#### 3.1 入选验证

- **跨域一致性**：能力在不同场景下是否稳定体现？否 → 不纳入
- **有预测力**：能否推断在新场景下的能力表现？否 → 降级为观察

#### 3.2 质量检验

通过入选验证的能力，逐条检验（详见 `resources/quality-reference.md`）：

- **有具体判断标准**：非空话，能判断何时适用
- **能指导日常决策**：能决定在具体场景下怎么做
- **跨场景适用**：不限于特定项目，能迁移

**验证结果**：

- 入选验证 + 质量检验均通过 → 核心能力
- 入选验证通过但质量检验部分通过 → 次要能力
- 入选验证未通过 → 不纳入

#### 3.3 提炼原则

- 每条能力用一句话概括，包含名称和具体表现
- 基于内容证据，不做主观臆断
- 从"如何感知/学习/推理/决策/其他"的角度理解，而非"做了什么"
- 必须通过质量三重检验
- 遵循隐私保护原则和避免套模板规则（详见 `resources/quality-reference.md`）

### 步骤 4. 输出能力模型分析报告

按照以下结构输出分析结果：

```markdown
## 能力模型分析报告

**用途**：用于指导 AI agent 的通用行为/底层能力

### 一、感知能力

- **能力名称**：一句话概括能力含义
- **能力名称**：一句话概括能力含义
  （可多项，也可无）

### 二、学习能力

- **能力名称**：一句话概括能力含义

### 三、推理能力

- **能力名称**：一句话概括能力含义

### 四、决策能力

- **能力名称**：一句话概括能力含义

### 五、其他能力

- **能力名称**：一句话概括能力含义
```

每个维度下能力数量不限，但每个维度至少提炼一条核心能力。无观察结果时标注"未识别到显著能力"。
