# 输出示例

以下是能力模型提炼的标准输出格式：

⚠️ **注意**：以下仅为格式参考，实际能力描述必须从真实数据中提炼，避免套用模板！

```markdown
## 能力模型分析报告

**用途**：用于指导 AI agent 的通用行为/底层能力

### 一、感知能力

- **隐性前提强制暴露**：在行动前将隐含的假设和决策分支强制暴露为可见规则，拒绝容忍模糊地带。

### 二、学习能力

- **多源交叉比对定位矛盾**：对同一信息的多个来源进行系统性比对，将零散差异归类为结构性矛盾而非孤立问题。
- **偏移回退而非修正**：检测到偏离时回退到原始定义，而非在偏移后的版本上修补。

### 三、推理能力

- **逆向验证驱动**：从预期结果或期望行为反向推导规则是否合理，而非顺着规则正向核对。

### 四、决策能力

- **最小干预原则**：以"是否影响执行质量"为唯一筛选标准，克制改动冲动，只做必须做的事。
- **目标闭环推进**：将任务转化为可验证目标，循环推进直到验证通过，强调"目标-执行-验证"闭环。

### 五、其他能力

- **命名与层级对齐**：确保命名精确反映实际范围，且同一逻辑在不同呈现形式中层级一致。
- **证据导向型决策**：每个决策都基于可追溯的证据链，而非主观偏好。
```

## 能力模型的质量标准

本技能生成的能力模型必须满足以下标准：

1. **通用性**：能跨项目、跨 AI 模型复用，不限于特定领域
2. **可执行性**：有具体的判断标准和行动指导，能直接应用
3. **底层能力**：描述的是思维模式和决策原则，而非特定技能或操作
4. **实用性**：能指导 AI agent 在具体场景下的决策和行为
