# 输出示例

以下是能力模型提炼的标准输出格式：

```markdown
## 能力模型分析报告

### 一、感知能力

- **主动探索未知领域**：倾向于主动发现和探索未知，而非等待信息到来。

### 二、学习能力

- **自上而下构建认知框架**：习惯先建立整体结构，再填充细节，从顶层设计驱动具体实现。
- **通过类比迁移知识**：善于发现不同事物间的相似性，用已知模式理解新问题。

### 三、推理能力

- **假设先行验证跟进**：提出假设后先验证，确认成立再推进，而非直接执行。

### 四、决策能力

- **追求一致性收敛**：倾向于统一标准、消除差异，向单一最优模式收敛。
- **迭代优化逼近目标**：不追求一次性完美，通过持续小改进逐步接近理想状态。

### 五、其他能力

- **偏好抽象而非具象**：倾向于从具体实例中提取抽象模式，而非停留在具体细节。
- **重视可复现性**：强调过程的可追溯和结果的可复现，建立标准化流程。

### 六、能力路径预测

| 场景       | 预测行为路径                                                                              |
| ---------- | ----------------------------------------------------------------------------------------- |
| 新建项目   | 1. 主动探索相关领域 → 2. 先搭建整体框架和目录结构 → 3. 小步迭代填充内容 → 4. 持续对齐收敛 |
| 面对新问题 | 1. 寻找类比对象 → 2. 提出假设 → 3. 验证假设 → 4. 基于验证结果迭代优化                     |
| 发现不一致 | 1. 识别差异 → 2. 建立统一标准 → 3. 分阶段对齐 → 4. 验证一致性                             |
| 优化流程   | 1. 观察现有模式 → 2. 抽象出可复用模式 → 3. 建立标准化流程 → 4. 迭代改进                   |
```
