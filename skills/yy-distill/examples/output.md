# 输出示例

```markdown
## 能力模型分析报告

### 一、数据概览

- 总提交数：200+ 次
- 时间跨度：约 2 个月
- 代码变化：新增 2 万+ 行，删除 1 万+ 行，净增约 8 千行
- 活跃天数（日均提交≥10）：约 2 周，平均每日约 8 次提交

---

### 二、感知能力

#### 主动探索未知领域

倾向于主动发现和探索未知，而非等待信息到来。

---

### 三、学习能力

#### 自上而下构建认知框架

习惯先建立整体结构，再填充细节，从顶层设计驱动具体实现。

#### 通过类比迁移知识

善于发现不同事物间的相似性，用已知模式理解新问题。

---

### 四、推理能力

#### 假设先行验证跟进

提出假设后先验证，确认成立再推进，而非直接执行。

---

### 五、决策能力

#### 追求一致性收敛

倾向于统一标准、消除差异，向单一最优模式收敛。

#### 迭代优化逼近目标

不追求一次性完美，通过持续小改进逐步接近理想状态。

---

### 六、其他能力

#### 偏好抽象而非具象

倾向于从具体实例中提取抽象模式，而非停留在具体细节。

#### 重视可复现性

强调过程的可追溯和结果的可复现，建立标准化流程。

---

### 七、维度间关联

- **感知→学习**：主动探索获取的信息为自上而下构建框架和类比迁移提供了丰富的素材输入
- **学习→推理**：通过类比迁移和框架构建获得的知识，为假设验证推理提供了可参考的已知模式
- **推理→决策**：假设验证的推理结果为一致性收敛和迭代优化决策提供了判断依据
- **反馈回路**：迭代优化的决策结果反过来驱动新一轮的主动探索，形成持续改进的闭环

---

### 八、能力关联图谱

    主动探索未知领域
           │
           ▼
    自上而下构建认知框架
           │
           ▼
    追求一致性收敛 ──────► 迭代优化逼近目标 ◄────── 假设先行验证跟进
           │
           ▼
    通过类比迁移知识

**关联说明**：

- 主动探索为框架构建提供信息输入
- 自上而下构建框架为一致性收敛提供结构基础
- 一致性收敛通过迭代优化逐步实现
- 假设先行验证为迭代优化提供安全保障
- 通过类比迁移知识为框架构建提供参考

---

### 九、能力路径预测

基于以上能力模型，可预测在面对以下场景时的行为路径：

| 场景       | 预测行为路径                                                                              |
| ---------- | ----------------------------------------------------------------------------------------- |
| 新建项目   | 1. 主动探索相关领域 → 2. 先搭建整体框架和目录结构 → 3. 小步迭代填充内容 → 4. 持续对齐收敛 |
| 面对新问题 | 1. 寻找类比对象 → 2. 提出假设 → 3. 验证假设 → 4. 基于验证结果迭代优化                     |
| 发现不一致 | 1. 识别差异 → 2. 建立统一标准 → 3. 分阶段对齐 → 4. 验证一致性                             |
| 优化流程   | 1. 观察现有模式 → 2. 抽象出可复用模式 → 3. 建立标准化流程 → 4. 迭代改进                   |

---

### 十、总结

核心能力模型体现了一种**"感知驱动、框架构建、迭代优化"**的能力组合：

1. **主动感知**：主动探索未知，发现潜在问题
2. **框架学习**：从顶层设计出发，通过类比迁移知识
3. **验证推理**：通过假设-验证降低风险
4. **迭代决策**：小步快跑，逐步逼近目标，向最优模式收敛

这种能力模型适合从事需要长期维护、多人协作、持续演进的项目，能够在复杂度增长时保持系统的可维护性和一致性。
```
