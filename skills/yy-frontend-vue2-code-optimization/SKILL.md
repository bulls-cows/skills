# yy-frontend-vue2-code-optimization

针对 Vue2 页面组件、JavaScript 和 CSS/SCSS/Less 文件的代码优化技能。通过统一代码结构、语义化命名、BEM 样式规范、逻辑分层和关键注释，显著提升代码可读性与团队协作效率，降低维护与交接成本。

**核心原则**：不生成新组件，不修改业务逻辑。涉及业务变更必须先确认。

## 触发场景

- 用户明确要求优化 Vue2 前端代码
- Code Review / 代码审查时需要优化代码结构
- 用户指定文件或文件夹进行优化（.vue/.js/.css/.scss/.less）
- 用户未指定文件时，自动优化当前 git 变动文件（含暂存区）
- 用户要求统一 BEM 命名规范、导入排序、格式化代码
- 用户要求进行语义化命名重构、异步代码优化、注释增强

## 不适用场景

- 生成新组件或新功能代码
- 修改业务逻辑、变更功能行为
- 生成 git 提交信息
- Vue3 项目（使用 yy-frontend-vue3-code-optimization）
- 非前端代码文件

## 支持优化的文件类型

| 扩展名  | 优化内容                                                    |
| ------- | ----------------------------------------------------------- |
| `.vue`  | Vue2 单文件组件完整优化（模板、脚本、样式）                 |
| `.js`   | JavaScript 文件优化（代码风格、导入排序、命名规范、注释）   |
| `.css`  | CSS 样式优化（BEM 命名、格式、注释）                        |
| `.scss` | SCSS 样式优化（BEM 命名、格式、注释）                       |
| `.less` | Less 样式优化（BEM 命名、格式、注释）                       |

## 执行流程

完整的优化规则和执行流程请查看 `prompts/skill-prompts.md`（主提示词）。

### 核心流程

1. **确定目标**：用户指定文件 → 递归收集；未指定 → git 变动文件
2. **生成任务清单**：逐文件扫描，生成带风险等级的任务表
3. **用户确认**：🟢零风险自动勾选，🟡中/低风险和🔴高风险需用户确认
4. **调度执行**：按确认的任务 ID 逐项执行
5. **输出结果**：执行摘要 + 变更后的完整代码

### 风险分级机制

| 风险等级 | 默认状态 | 包含任务 |
|---------|---------|---------|
| 🟢 零风险 | ✅ 自动勾选 | 业务逻辑梳理、代码风格清洗、文档注释增强 |
| 🟡 低/中风险 | ❌ 需确认 | CSS/BEM 重构、语义化命名重构 |
| 🔴 高风险 | ❌ 逐项确认 | async/await 转换、computed 迁移、逻辑拆分 |

**交互指令**：`全部执行`、`全部跳过`、`确认`、`执行 T01 T03` 等。

## 边界条件与注意事项

- **scoped 样式**：进行 BEM 重构时，必须同步修改模板中的 `class` 属性
- **跨文件引用**：语义化命名重构涉及跨文件引用时，需提示用户范围并确认
- **== vs ===**：运算符转换属于逻辑变更，必须单独确认
- **回滚机制**：建议用户使用 git 管理变更，优化前可提醒提交
- **大型文件**：超过 1000 行的文件建议分批优化

## 输出契约

- ✅ 不修改业务逻辑，保持原有功能
- ✅ 确保 Vue 2 Options API 语法正确
- ✅ 模板只负责展示，不写复杂表达式
- ✅ 专业、客观、简洁的输出风格
- ✅ 清晰展示变更内容和执行状态
