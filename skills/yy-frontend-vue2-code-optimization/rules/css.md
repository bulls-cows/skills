# CSS 样式规范

## CSS 处理

- 预处理器：Sass/SCSS、Less
- 格式化：csscomb + prettier
- 全局样式：`src/styles/`

## 样式区注释与作用域

### 注释格式

| 场景 | 注释格式 | 示例 |
|------|----------|------|
| 模块分组 | `/* 模块名称 */` | `/* 用户卡片 */` |
| 子模块 | `/* 模块 > 子模块 */` | `/* 用户卡片 > 头部 */` |
| 响应式 | `/* 响应式 */` | `/* 响应式 */` |

### 作用域

- `scoped`：仅作用于当前组件
- 非 `scoped`：需标注 `/* 全局 */`
- 优先使用 `scoped`

## 响应式适配

- 使用媒体查询 `@media` 适配不同屏幕
- 移动端优先：先写移动端，再通过媒体查询增强 PC 端
