# 输出示例

本文档展示使用 yy-design-ui 技能设计界面后的预期输出示例。

## 示例 1：后台管理系统 Dashboard

### 用户请求

帮我设计一个后台管理系统 dashboard 界面

### 输出说明

**设计说明**：

- 配色方案：深蓝灰侧边栏（#1e293b）+ 浅灰背景（#f1f5f9），蓝色强调色（#3b82f6）
- 字体选择：系统默认字体（苹方/思源黑体），行高 1.6
- 设计理念：左侧固定导航 + 右侧内容区经典布局，SVG 实现图表，留白充足

**技术实现**：

- 纯原生 CSS，无任何 CSS 框架依赖
- SVG 图表：折线图和环形图均使用 SVG 实现
- 无外部资源：完全离线可用
- 响应式设计：适配桌面、平板、手机

**功能模块**：

1. 侧边栏：Logo + 导航菜单 + 用户信息
2. 顶部栏：标题 + 搜索框 + 通知
3. 统计卡片：用户数、订单量、销售额、转化率
4. 销售趋势图：SVG 折线图，支持周/月/年切换
5. 用户来源图：SVG 环形图 + 图例
6. 最近订单：订单列表，显示状态
7. 热门商品：商品列表，显示销量

### 完整代码

详见 `examples/dashboard-demo.html`。

## 示例 3：产品落地页（Hero + 特性 + 更新记录）

### 用户请求

设计一个前端监控产品的落地页

### 输出说明

**设计说明**：

- 配色方案：蓝色主色（#1890ff）搭配浅灰背景（#fafafa），白色卡片区域
- 字体选择：系统默认字体（苹方/思源黑体），行高 1.8
- 设计理念：Badge + 大标题 Hero 引导，特性网格展示产品能力，时间线展示更新历史

**技术实现**：

- 纯原生 SCSS/CSS，BEM 命名规范
- 无外部依赖
- 响应式适配：968px/640px 两个断点
- 关键动画：pulse（badge 圆点）、float（视觉卡片）

**Hero 区域结构**：

```text
┌─────────────────────────────────────────────┐
│  [●] 前端监控首选      ┌──────────────────┐ │
│                        │ ● ● ●            │ │
│  BetterMonitor         │                  │ │
│                        │  视觉卡片区域     │ │
│  简洁高效的前端日志    │  （浮动动画）     │ │
│  监控系统              │                  │ │
│                        └──────────────────┘ │
│  [立即使用] [查看文档]                       │
└─────────────────────────────────────────────┘
```

**功能模块**：

1. Hero 区域：Badge 标签 + 主标题 + 副标题 + 描述 + 双按钮 + 视觉卡片
2. 特性网格：3 列网格展示产品核心特性，hover 时上浮 + 阴影
3. 代码展示：CDN/NPM 安装方式 tab 切换
4. 截图预览：产品截图 tab 切换查看
5. 更新记录：垂直时间线展示版本历史
