# 输入示例

本文档展示用户请求创建交接文档的典型输入示例。

## 示例 1：创建交接文档

```text
给我补一个 handoff.md，专门给新会话接力用。
```

## 示例 2：询问如何续接

```text
新开一个 AI 会话时，如何告诉 AI 继续这个任务？
```

## 示例 3：整理当前任务上下文

```text
把当前规格、限制、进度整理成一个可复用的交接文档。
```

## 示例 4：更新现有交接文档

```text
更新 handoff.md，把刚才完成的步骤标记为已完成。
```

## 示例 5：指定存放位置

```text
生成 handoff.md，放在 .claude/specs/20260326_120000_some-task/ 目录下。
```

## 示例 6：包含特定约束

```text
创建 handoff.md，确保包含以下约束：
1. 不使用 TypeScript
2. 必须兼容 IE11
3. 样式使用 BEM 命名
```
