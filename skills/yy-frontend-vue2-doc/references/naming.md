# 注释命名规范

## 模板区注释命名

| 节点类型     | 命名规则                                  | 示例                                  |
| ------------ | ----------------------------------------- | ------------------------------------- |
| 根节点       | 使用组件 `name` 值（PascalCase）          | `<!-- UserCard -->`                   |
| 循环节点     | `循环: ` + 数据业务含义                   | `<!-- 循环: 用户列表 -->`             |
| 条件节点     | `条件: ` + 条件业务含义                   | `<!-- 条件: 有编辑权限时 -->`         |
| 区块         | 区域功能描述（名词或名词短语）            | `<!-- 搜索表单区域 -->`               |
| 插槽         | `插槽: ` + slot name 值                   | `<!-- 插槽: footer -->`               |
| 动态组件     | `动态组件: ` + 组件用途                   | `<!-- 动态组件: 不同角色表单 -->`     |

## 脚本区注释命名

### 组件级

| 节点       | 命名规则                              | 示例                              |
| ---------- | ------------------------------------- | --------------------------------- |
| 组件名称   | `// name: ` + `name` 属性值           | `// name: UserCard`               |
| 引入组件   | `// component: ` + 组件名列表         | `// component: Icon, UserAvatar`  |

### Props / Data

| 节点     | 命名规则                                    | 示例                              |
| -------- | ------------------------------------------- | --------------------------------- |
| props    | `// ` + prop 键名 + `: ` + 中文描述         | `// user: 用户信息对象`           |
| data     | `// ` + 属性键名 + `: ` + 中文描述          | `// isLoading: 加载状态`          |

### Computed / Watch

| 节点       | 命名规则                                    | 示例                              |
| ---------- | ------------------------------------------- | --------------------------------- |
| computed   | `// computed: ` + 中文描述                  | `// computed: 是否全选状态`       |
| watch      | `// watch: ` + 中文描述                     | `// watch: 监听搜索条件变化`      |

### Methods

| 场景         | 命名规则                                        | 示例                              |
| ------------ | ----------------------------------------------- | --------------------------------- |
| 普通方法     | `// methods: ` + 中文描述                       | `// methods: 提交表单数据`        |
| 关键方法     | JSDoc 块注释，首行为方法名                      | `/** 获取用户信息 */`             |
| 事件处理方法 | `// methods: ` + 触发场景 + 操作                 | `// methods: 点击提交按钮时提交`  |

### 生命周期

| 钩子       | 命名规则                            | 示例                      |
| ---------- | ----------------------------------- | ------------------------- |
| created    | `// lifecycle: created`             | `// lifecycle: created`   |
| mounted    | `// lifecycle: mounted`             | `// lifecycle: mounted`   |
| updated    | `// lifecycle: updated`             | `// lifecycle: updated`   |
| destroyed  | `// lifecycle: destroyed`           | `// lifecycle: destroyed` |

### Provide / Inject

| 节点     | 命名规则                                        | 示例                              |
| -------- | ----------------------------------------------- | --------------------------------- |
| provide  | `// provide.` + 键名 + `: ` + 中文描述          | `// provide.appConfig: 全局配置`  |
| inject   | `// inject.` + 键名 + `: ` + 中文描述           | `// inject.parentData: 父组件数据`|

## 命名禁止项

- 禁止使用无意义的描述（如「这是一个方法」「处理一些数据」）
- 禁止注释内容与代码功能无关（如「这里是代码」「以下代码」）
- 禁止英文描述（代码标识符除外）
