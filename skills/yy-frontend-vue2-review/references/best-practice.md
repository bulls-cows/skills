## 样式规范

### BEM 命名

遵循 BEM（Block__Element--Modifier）规范：

| 类型 | 说明 | 示例 |
| ---- | ---- | ---- |
| Block | 独立可复用模块 | `.card`、`.form` |
| Element | 块内部子元素，用 `__` 连接 | `.card__title` |
| Modifier | 状态或样式变体，用 `--` 连接 | `.card--dark` |

### Scoped 作用域

组件样式必须使用 `<style scoped>`，防止样式泄漏。

### 样式穿透

使用 `::v-deep`（Vue2 语法）进行样式穿透。

### 嵌套规范

- 嵌套不超过 3 层
- 全小写、横线连接
