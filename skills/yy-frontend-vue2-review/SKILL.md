# Vue2 前端代码审核助手

审核 Vue2 项目中 `src` 目录下所有改动文件（`.vue`、`.js`、`.css`、`.scss`、`.less`），按 9 大维度逐项检查并生成审核清单。

**核心原则：绝不审核 `src` 之外的文件，绝不用 React 或 Vue3 标准，绝不修改代码（除非用户明确要求修复）。**

## 触发场景

- 用户明确要求审核 Vue2 前端代码
- 代码合并前全面审核
- 代码提交前质量检查
- 用户指定 `src` 目录下特定文件或文件夹范围
- 默认审核 `git diff` 获取的 `src` 目录下所有变动文件

## 不支持场景

- 非 Vue2 项目（React、Vue3、Angular 等）
- 项目不存在 `src` 目录
- 审核 `src` 目录之外的文件
- TypeScript 文件（.ts）
- 直接修改代码自动化修复（除非用户明确要求）

## 支持文件类型

| 扩展名  | 审核范围                                                       |
| ------- | -------------------------------------------------------------- |
| `.vue`  | Vue2 单文件组件（模板、脚本、样式）                            |
| `.js`   | 代码风格、组件规范、命名、网络请求、computed、逻辑错误、禁止项 |
| `.css`  | 样式格式、BEM 命名                                             |
| `.scss` | 样式格式、BEM 命名、嵌套规范                                   |
| `.less` | 样式格式、BEM 命名、变量使用                                   |

---

## 执行流程

### 阶段一：获取审核目标

1. **目录验证**：检查项目是否存在 `src` 目录。不存在则终止。
2. **用户指定**：递归收集指定文件/文件夹内的 `.vue`、`.js`、`.css`、`.scss`、`.less`。
3. **未指定**：执行 `git diff --name-only HEAD` 和 `git diff --cached --name-only`，合并去重后严格过滤出 `src` 目录下文件。
4. **无匹配文件**：回复「当前 src 目录下没有需要审核的改动文件。」并终止。

### 阎段二：生成审核清单

| 维度 ID | 检查内容                                                                  | 严重程度 | 详细规范                      |
| ------- | ------------------------------------------------------------------------- | -------- | ----------------------------- |
| D01     | 代码风格（2 空格缩进、JS 单引号、分号、尾随逗号、箭头函数、3 组导入顺序） | 🟢 轻微  | `references/code-style.md`    |
| D02     | 最佳实践（调试代码、scoped、未使用变量等）                                | 🟢 轻微  | `references/best-practice.md` |
| D03     | Vue2 组件规范（脚本结构、Props、Emit 等）                                 | 🟡 中等  | `references/component.md`     |
| D04     | 命名规范（API、事件、常量、组件名等）                                     | 🟡 中等  | `references/naming.md`        |
| D05     | 网络请求规范（async/await、统一响应等）                                   | 🟡 中等  | `references/request.md`       |
| D06     | computed 规范（try/catch、有意义命名）                                    | 🟡 中等  | `references/computed.md`      |
| D07     | 逻辑错误（空指针、数组越界、判断遗漏等）                                  | 🔴 严重  | `references/logic.md`         |
| D08     | 安全漏洞（XSS、敏感信息泄露）                                             | 🔴 严重  | `references/security.md`      |
| D09     | 绝对禁止项（连续解构、修改 props 等）                                     | 🔴 严重  | `references/forbidden.md`     |

**审核执行规则**：

- **🔴 严重（D07/D08/D09）**：发现即审核不通过，必须修复。
- **🟡 中等（D03/D04/D05/D06）**：发现则列出，审核不通过，建议修复。使用 mixins 属于中等问题（建议重构但不强制）。
- **🟢 轻微（D01/D02）**：发现则列出，不影响审核通过结论。

### 阎段三：逐文件逐维度审核

按文件 × 维度生成审核矩阵，按 D01 → D09 顺序逐项检查。

### 阎段四：结果汇总与判断

- 存在严重/中等问题 → ❌ 不通过，输出问题详情和修复建议
- 仅轻微问题或无问题 → ✅ 通过，输出审核报告

## 输出格式

### 审核清单展示

```markdown
## 审核结果

- 📁 审核文件：X 个
- ❌ 不通过 / ✅ 通过

| 文件    | D01 | D02 | D03 | D04 | D05 | D06 | D07 | D08 | D09 |
| ------- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| xxx.vue | ✅  | ⚠️  | ✅  | ❌  | -   | ✅  | -   | ✅  | ✅  |
```

### 🟢 通过（无问题或仅轻微）

```markdown
## 审核通过

**✅ 结论：通过**（仅轻微问题或无问题）

**问题统计**：

- 🔴 严重：0
- 🟡 中等：0
- 🟢 轻微：X

[轻微问题详情（可选）]
```

### 🔴 不通过（严重或中等问题）

```markdown
## 审核不通过

**❌ 结论：不通过**

**问题统计**：

- 🔴 严重：X
- 🟡 中等：Y
- 🟢 轻微：Z

---

### 🔴 严重问题

[按文件分组、严重程度排序输出问题及修复建议]

---

### 🟡 中等问题

[按文件分组输出问题及修复建议]
```
