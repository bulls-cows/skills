# 构建工具

构建工具负责技能的校验、格式化和市场配置同步，通过 `npm run lint` 触发。

## 目录结构

```text
build/
  check-skill.mts       # 技能文件校验
  convert-crlf-to-lf.ts # 换行符转换
  sync-marketplace.mts  # 市场配置同步
```

## 核心组成

- `check-skill.mts`：校验 SKILL.md 的 YAML frontmatter 格式、description 折叠语法、章节完整性
- `convert-crlf-to-lf.ts`：将 CRLF 换行符转换为 LF，确保跨平台一致性
- `sync-marketplace.mts`：扫描 skills/ 目录，自动生成 `.claude-plugin/marketplace.json`，禁止手动修改该文件

## 配置与使用

```bash
# 执行全部 lint 检查（包含技能校验、换行符转换、市场配置同步）
npm run lint
```

lint 脚本会依次执行：换行符转换 → 技能校验 → 市场配置同步。任何步骤失败都会阻止后续步骤。
