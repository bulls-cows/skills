# 规则系统

规则是对 AI 行为的约束性文档，以 `RULE.md` 为载体，通过 `@` 语法在 `AGENTS.md` 中引用后生效。规则与技能的区别：规则是被动约束，技能是主动工作流。

## 目录结构

```text
rules/
  file-scope-limit/RULE.md
  frontend-rules-vue2/RULE.md
  frontend-rules-vue3/RULE.md
  markdown/RULE.md
  npm/RULE.md
  text/RULE.md
```

## 核心组成

- `file-scope-limit`：文件修改范围限制，要求 AI 在授权目录内操作，跨目录需获得用户明确授权
- `frontend-rules-vue2`：Vue2 前端开发规范，涵盖 Options API 组件结构、命名、样式等
- `frontend-rules-vue3`：Vue3 前端开发规范，涵盖 Composition API、script setup、Hooks 等
- `markdown`：Markdown 书写规范，要求围栏代码块声明语言标识，简单映射优先用列表而非表格
- `npm`：npm 包发布与版本管理规范
- `text`：文本表达规范，要求默认中文、精简专业、克制客观、面向执行

## 引用方式

规则通过 `AGENTS.md` 的 `## 需要遵守的规则` 章节引用：

```markdown
[规则名称 @rules/规则目录/RULE.md](./rules/规则目录/RULE.md)
```

引用后，AI 在执行任务时会自动遵循规则内容。
