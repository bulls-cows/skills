# 技能系统

技能是本仓库的核心产出物，每个技能是一个独立的 `SKILL.md` 文件，定义了可按需加载的任务工作流。技能通过 `description` 字段实现自动发现与精确触发，避免上下文膨胀。

## 核心组成

### 公共技能（skills/）

按功能域分组：

- **代码质量**
  - `yy-review`：审核 git 变动文件的语法、逻辑、安全和最佳实践
  - `yy-lint`：执行代码风格检查
  - `yy-comment`：为代码添加 JSDoc 注释和内部逻辑注释
  - `yy-frontend-vue2-review`：Vue2 前端代码审核，覆盖 9 大审核维度
  - `yy-frontend-vue3-review`：Vue3 前端代码审核，基于 Vue3 开发规范逐项检查
- **代码优化**
  - `yy-frontend-vue2-code-optimization`：Vue2 代码标准化与优化（BEM 样式、命名、导入排序等）
  - `yy-frontend-vue3-code-optimization`：Vue3 代码标准化与优化（script setup、Hooks 规范等）
  - `yy-optimize`：生成优化方案供用户选择，不直接执行改动
- **创建与生成**
  - `yy-create-skill`：创建或更新符合规范的 Skill 技能文件
  - `yy-create-rule`：创建或更新规则文档，并更新 AGENTS.md 引用
  - `yy-create-readme`：创建或更新项目 README.md
  - `yy-create-report`：生成工作报告
  - `yy-create-wiki`：为项目生成结构化的 Wiki 文档
  - `yy-design-ui`：创建符合国人审美的网页界面设计
- **Git 操作**
  - `yy-commit`：生成规范的中文提交信息并执行提交
  - `yy-frontend-commit`：前端项目提交助手，归纳 src 目录改动生成提交信息
- **项目初始化**
  - `yy-init`：初始化或更新项目的 AGENTS.md 文档
  - `yy-handoff`：创建跨会话续接的交接文档
  - `yy-refresh`：刷新 AI 对代码的理解，同步最新改动
- **执行模式**
  - `yy-mode-plan`：计划优先执行模式，变更前先制定计划
  - `yy-mode-spec`：规格优先开发模式，编码前制定详细规格
  - `yy-run-skills`：串行执行多个技能
- **内容处理**
  - `yy-read-pdf`：读取并解析 PDF 文件内容
  - `yy-wechat-to-markdown`：将微信公众号文章转换为 Markdown
  - `yy-post-to-wechat`：通过公众号 API 将 Markdown 文章发布到草稿箱
  - `yy-distill`：从指定内容中提炼思维方式
  - `yy-skills-reverse-analysis`：将技能文件逆向还原成系统提示词

### 内部技能（skills-internal/）

用于仓库自身维护，不对外分发：

- `yy-check-skills-consistency`：检查 README.md 技能列表与 skills/ 目录的一致性
- `yy-sync-thinking-method`：同步"AI 思考方式"在 AGENTS.md、模板文件、yy-optimize 之间的一致性
- `yy-sync-instructions-from-opencode`：将 `.opencode.json` 中的通用规则同步到 `AGENTS.md`

## 技能文件结构

每个技能目录包含一个 `SKILL.md`，部分技能包含辅助目录：

- `templates/`：模板文件（内容超过 20 行时独立存放）
- `resources/`：参考文档
- `examples/`：输入输出示例

SKILL.md 的 YAML frontmatter 只允许 `name` 和 `description` 两个字段，`description` 使用 `>` 折叠式语法。
