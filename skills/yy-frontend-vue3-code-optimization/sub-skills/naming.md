# T05 🔤 语义化命名重构（🟡 中风险）

**定位**：🟡 中风险。涉及标识符的全局替换，需确保引用查找的准确性。

## 相关规则

执行本任务前，请先阅读以下规则文件（位于 `rules/` 目录），按优先级从高到低排列：

- **`rules/spec-index.md`**：Vue3 前端项目开发规范总纲（必读）
- **`rules/naming.md`**：文件与组件命名、标识符命名、Vue3 组合式 API 命名、CSS BEM 命名规范
- **`rules/hooks.md`**：Hooks 命名规范（必须以 `use` 开头）

> 详细命名规范已整理至 `rules/naming.md`，本文件仅保留 T05 任务的执行策略。

## 执行策略

1. **全局查找**：使用 LSP 或 AST-grep 查找所有引用，确保不遗漏任何引用点
2. **分类替换**：按作用域范围（单文件 → 组件内 → 跨组件 Hooks → 全局 API）逐个替换
3. **diff 预览**：展示变更前后的 diff 格式，确认无误后执行

## 风险说明

| 风险项 | 影响范围 | 说明 |
|--------|----------|------|
| **引用遗漏** | 全局 | 全局搜索可能遗漏动态字符串引用（如 `this[name]`） |
| **第三方库冲突** | 全局 | 某些标识符可能是第三方库 API 名称，不应修改 |
| **API 路径变更** | 全局 | API 函数重命名不应改变后端请求路径 |

## 变更预览格式

```diff
- const userInfo = await apiGetUserInfo(userId.value)
+ const userData = await apiGetUserInfo(userId.value)
```

## 注意事项

- **仅做命名变更，不修改逻辑行为**
- **API 函数重命名时，保持 HTTP 请求路径不变**
- **TypeScript 类型重命名后，确认类型引用已同步更新**
- **组件名变更时，同步更新组件注册（如有）**
