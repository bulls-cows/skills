# 输入示例

本文档展示用户如何请求生成工作报告。

## 示例 1：生成默认工作报告

```text
生成工作报告
```

或：

```text
汇总工作
```

## 示例 2：生成指定时间范围的报告

```text
生成本周工作报告
```

或：

```text
生成上周工作报告
```

或：

```text
生成 2024-01-01 到 2024-01-15 的工作报告
```

## 示例 3：生成指定账号的报告

```text
生成张三的工作报告
```

或：

```text
生成工作报告 --author "张三"
```

或：

```text
生成 zhangsan@example.com 账号的工作报告
```

## 示例 4：组合参数

```text
生成上周张三的工作报告
```

或：

```text
生成 2024-01-01 到 2024-01-15 期间 zhangsan@example.com 的工作报告
```
