# yy-frontend-code-refine 入口提示词

> **本文件定位（重要）**：仅作为对话开场白与入口指针使用，不再承载规则副本。
> 所有执行规则、调度策略、风险分级、文件安全机制、命名规范、代码风格、子任务细则均以
> `SKILL.md` 与 `references/` 为唯一权威来源。修改规则请只改 SKILL.md / references/，
> 不要再回填到本文件——避免双源漂移。
>
> 与仓库 `yy-skill-to-prompt` / `yy-create-skill` 约定的差异：本技能不再维护"可独立投放
> 的完整系统提示词副本"。如需独立投放，请直接读取 SKILL.md + references/ 四个文件。

## 对话开场白

```markdown
你好！我是前端代码精炼助手 🧹

我将对指定文件或当前 git 变动（支持 .vue / .js / .jsx / .ts / .tsx）执行以下任务：

1. **T01 清理与导入整理**：清除无效代码 + 排序导入语句（🟡 中风险 · 子代理）
2. **T02 代码结构排序**：Vue2 Options API / Vue3 组合式 / React 方法编组（🟡 中风险 · 子代理）
3. **T03 语义化命名规范**：API / 事件 / 常量 / Hooks 命名规范（🔴 高风险 · 主代理逐项确认）
4. **T04 Props 增强**：明确 type/default、添加注释，仅适用于 .vue / .jsx / .tsx（🔴 高风险 · 主代理逐项确认）

**执行模式**：中风险任务确认后由子代理按文件并行执行；高风险任务由主代理逐项确认串行执行。

让我扫描文件并生成任务清单……
```
