# 前端专项审核规则

## 审查维度

- DOM 与模板：语义化标签、无障碍访问、事件绑定、模板语法正确性
- 样式与布局：选择器复杂度、命名规范、响应式设计、样式隔离
- 组件设计：职责单一、Props/Emits 规范、组件通信、生命周期使用
- 状态与数据流：状态管理、数据流向、异步数据处理、内存泄漏
- 性能：渲染优化、懒加载、打包体积、重渲染控制
- 安全：XSS、危险内容渲染、敏感数据暴露
- 可维护性：命名语义化、代码重复、导入规范、可复用性

## 严重

- XSS 漏洞：使用 `v-html`、`dangerouslySetInnerHTML`、`innerHTML` 渲染用户输入或未转义内容
- 敏感信息暴露：API 密钥、Token、密码等硬编码在前端代码中
- 内存泄漏：定时器、事件监听器在组件卸载时未清理；组件卸载后仍尝试更新状态
- 状态管理错误：直接修改 Props、异步更新导致状态竞态、未清理的订阅
- 模板编译错误：未闭合的标签、错误的指令语法、循环中缺少 key 导致的状态错乱

## 中等

- 渲染性能：缺少 memo/useMemo/useCallback 导致不必要重渲染、大列表未虚拟化、图片未懒加载
- 组件设计缺陷：组件职责过多、Props 缺少类型校验或默认值、回调未做防抖/节流
- 样式问题：`!important` 滥用、全局样式污染、z-index 层级混乱、scoped 样式穿透不当
- 异步处理不当：Promise 未处理、loading 状态未复位、并发请求未做竞态处理、错误状态未回滚
- 响应式设计缺陷：硬编码像素宽度、缺少断点适配、容器溢出未处理
- 可访问性缺失：交互元素缺少 aria 属性、键盘导航不可达、表单缺少 label、语义化标签使用不当
- 关联变更不完整：新增组件后路由、导航、导入、样式未同步；删除组件后引用未清理
- 资源加载风险：第三方脚本无 fallback、大资源无 loading 状态、CDN 资源无错误处理

## 轻微

- 调试代码遗留：`console.log`、`debugger`、临时注释、TODO 标记
- 命名与表达：变量名过短或不够语义化、注释与代码不同步、导入排序不规范
- 格式问题：代码缩进不一致、多余空行、模板格式轻微不规范
- 样式轻微问题：冗余样式声明、未使用的 CSS 类、颜色值格式不统一
