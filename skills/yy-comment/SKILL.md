# yy-comment

## 描述

为代码文件添加规范的注释，包括 JSDoc 文档注释和内部逻辑注释。支持整个文件或指定函数的注释添加。同时支持为 HTML、Vue 模板和 JSX/TSX 中的关键结构节点和交互区域添加模板注释，以及为 CSS/SCSS/LESS 样式文件添加区块和规则注释。

## 使用场景

- 用户要求为代码文件添加注释
- 用户要求为特定函数添加注释
- 用户要求为 HTML 文件或 Vue 模板添加注释
- 用户要求为 CSS/SCSS/LESS 样式文件添加注释
- 用户说以下内容时：
  - "给这个文件加注释"、"添加注释"
  - "为 xxx 函数添加 JSDoc"、"给 xxx 函数加文档"
  - "补充代码注释"、"这个函数需要注释"
  - "给模板加注释"、"给 HTML 加注释"
  - "给 template 部分加注释"、"为页面结构加注释"
  - "给样式加注释"、"给 CSS 加注释"

不应触发：

- 用户要求直接实现新功能
- 用户要求修改代码逻辑
- 用户要求删除代码
- 文件或函数已有完整注释，用户未明确要求补充
- 用户要求为每个 HTML 标签都加注释
- 用户要求为每条 CSS 规则都加注释

## 基础原则

- 已有的注释如果内容正确，保持原样不动，仅在缺失注释的位置补充新注释
- 注释使用中文编写
- 注释应解释"为什么"而非"是什么"，避免重复代码本身的含义
- 仅对重要逻辑添加注释，避免过度注释
- 保持注释简洁，一行即可说明清楚
- 已有的注释如果内容与代码不符或已过时，修正为准确描述

## 基础规范

### 文件类型与注释语法

| 文件类型                  | 注释语法                     |
| ------------------------- | ---------------------------- |
| `.js`/`.ts`/`.jsx`/`.tsx` | JSDoc `/** */` 和行注释 `//` |
| `.html`、Vue `<template>` | `<!-- 注释 -->`              |
| `.jsx`/`.tsx`（JSX 部分） | `{/* 注释 */}`               |
| `.css`                    | `/* 注释 */`                 |
| `.scss`/`.less`           | `/* 注释 */` 或 `//`         |

### Vue SFC 注释体系

Vue SFC 文件中三个区块各自使用对应的注释语法，互不干扰：

- `<template>`：`<!-- -->`
- `<script>`：JSDoc `/** */` 和 `//`
- `<style>`：`/* */`

## 指令

1. **确定注释范围**
   - 若用户指定文件：读取目标文件内容，识别所有函数定义
   - 若用户指定特定函数：定位目标函数，分析其功能和参数
   - 若用户未指定：询问用户需要为整个文件还是特定函数添加注释
   - 识别文件中是否包含 HTML 模板内容：
     - 纯 HTML 文件（`.html`）：整个文件视为模板内容
     - Vue SFC（`.vue`）：提取 `<template>` 部分视为模板内容
     - JSX/TSX 文件（`.jsx`/`.tsx`）：识别 return 语句中的 JSX 表达式视为模板内容
     - 不含模板内容的文件：仅执行步骤 2 和步骤 3
   - 识别文件中是否包含 CSS 样式内容：
     - 纯样式文件（`.css`/`.scss`/`.less`）：整个文件视为样式内容
     - Vue SFC（`.vue`）：提取 `<style>` 部分视为样式内容

2. **添加文档注释**
   - 在每个函数定义上方添加 JSDoc 注释
   - 在类定义和类方法上方添加 JSDoc 注释
   - 在 TypeScript interface、type、enum 定义上方添加文档注释
   - 在重要的模块级常量上方添加文档注释
   - 包含功能描述
   - 使用 `@param` 标签描述参数
   - 使用 `@returns` 标签描述返回值
   - 使用 `@throws` 标签描述可能抛出的异常（如有）
   - 详细规范见 `references/script.md`

3. **添加内部逻辑注释**
   - 识别函数体内部的重要逻辑
   - 在关键步骤前添加单行注释
   - 注释应解释"为什么"而非"是什么"
   - 避免对显而易见的代码添加注释
   - 详细规范见 `references/script.md`

4. **添加模板和样式注释**
   - 若文件包含 HTML 模板内容：
     - 识别模板中的关键节点（依据 `references/template-style.md` 的判断标准）
     - 在关键节点上方添加注释
     - HTML/Vue 模板使用 `<!-- 注释 -->`，JSX/TSX 使用 `{/* 注释 */}`
     - 仅对关键节点注释，不为每个标签添加
   - 若文件包含 CSS 样式内容：
     - 识别样式中的关键区块（依据 `references/template-style.md` 的判断标准）
     - 使用 `/* 注释 */` 格式，SCSS/LESS 中也可使用 `//` 行注释
     - 仅对关键区块注释，不为每条规则添加

5. **输出结果**
   - 修改目标文件，添加注释
   - 列出添加注释的函数列表
   - 说明添加的注释内容（文档注释、内部逻辑注释、模板注释和样式注释数量）
