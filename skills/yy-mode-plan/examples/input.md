# 输入示例

本文档展示用户请求制定计划的典型输入示例。

## 示例 1：制定计划

```text
/yy-mode-plan
添加基于 JWT 令牌的用户认证
```

## 示例 2：指定目录

```text
/yy-mode-plan --tool-dir .agents --plan-file jwt-auth
添加基于 JWT 令牌的用户认证
```

## 示例 3：要求细化计划

```text
请细化你的方案，比如你提到了精简指令步骤，具体如何精简？
```

## 示例 4：选择方案

```text
采用方案 A
```

## 示例 5：确认执行

```text
确认执行
```
