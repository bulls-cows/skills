# 输入示例

本文档展示用户请求制定计划的典型输入示例。

## 示例 1：制定计划

```text
/yy-mode-plan
添加基于 JWT 令牌的用户认证
```

## 示例 2：需求不明确时的澄清

```text
优化这个组件
```

AI 可能提问：

```text
需要澄清几个问题：
1. "优化"是指性能优化还是代码结构优化？
2. 这个组件是指哪个组件？
```

用户回答后，AI 继续澄清或进入方案方向。

## 示例 3：指定目录

```text
/yy-mode-plan --tool-dir .agents --plan-file jwt-auth
添加基于 JWT 令牌的用户认证
```

## 示例 4：确认方案方向

```text
方向正确，继续细化
```

或：

```text
方法二更合适，按方法二来
```

## 示例 5：要求细化计划

```text
请细化你的方案，比如你提到了精简指令步骤，具体如何精简？
```

## 示例 6：选择方案

```text
采用方案 A
```

## 示例 7：确认执行

```text
确认执行
```
