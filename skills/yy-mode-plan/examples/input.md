# 输入示例

本文档展示用户请求制定计划的典型输入示例。

## 示例 1：制定计划

```text
/yy-mode-plan
添加基于 JWT 令牌的用户认证
```

## 示例 2：需求不明确时的澄清

```text
优化这个组件
```

AI 可能提问：

```text
需要澄清几个问题：
1. "优化"是指性能优化还是代码结构优化？
2. 这个组件是指哪个组件？
```

用户回答后，AI 继续澄清或进入展示方案方向。

## 示例 3：指定计划文件目录

```text
/yy-mode-plan
计划文件放在 .claude/plans/ 下
添加基于 JWT 令牌的用户认证
```

## 示例 4：确认方案方向

```text
方向正确，继续细化
```

或：

```text
方法二更合适，按方法二来
```

## 示例 5：确认计划

```text
确认执行
```

## 示例 6：拒绝计划

```text
步骤 3 的实现方式有问题，换成用中间件拦截
```

AI 根据反馈调整计划，重新展示。

## 示例 7：执行中计划偏移

```text
发现现有接口结构与计划假设不同，需要调整步骤 2
```

AI 说明偏差和调整方案，等待用户确认后继续。
