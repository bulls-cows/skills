## 示例 2：审核不通过

````markdown
## 审核结果：不通过

### 问题统计

- 审核文件数：3
- 严重：1 个
- 中等：2 个
- 轻微：3 个

### 问题详情

#### 严重问题

1. **问题类型**：空指针风险
   - **位置**：src/utils/auth.ts:45
   - **描述**：未检查 token 为 null 的情况直接调用 split 方法
   - **影响**：当 token 为 null 时会导致运行时崩溃
   - **代码片段**：
     ```typescript
     const payload = JSON.parse(atob(token.split('.')[1]))
     ```
   - **修复建议**：添加 null 检查，如 `if (!token) return null;`

#### 中等问题

1. **问题类型**：未处理 Promise 异常
   - **位置**：src/api/user.ts:23
   - **描述**：fetchUserInfo 返回的 Promise 未添加 catch 处理
   - **影响**：网络错误或接口异常时无法捕获，可能导致未处理的 Promise 拒绝
   - **修复建议**：添加 .catch() 或使用 try-catch 包裹

2. **问题类型**：边界条件未处理
   - **位置**：src/utils/pagination.ts:15
   - **描述**：分页函数未处理 page 小于 1 的情况
   - **影响**：传入非法页码时可能产生意外行为
   - **修复建议**：添加边界检查，如 `page = Math.max(1, page)`

#### 轻微问题

1. **问题类型**：调试代码未移除
   - **位置**：src/components/Header.vue:18
   - **描述**：存在 console.log 语句
   - **修复建议**：移除调试代码

2. **问题类型**：命名不规范
   - **位置**：src/api/user.ts:8
   - **描述**：变量名 `u` 过于简短，不利于理解
   - **修复建议**：使用更具描述性的名称，如 `user`

3. **问题类型**：重复代码
   - **位置**：src/utils/format.ts:25-30
   - **描述**：与 src/utils/format.ts:45-50 存在重复逻辑
   - **修复建议**：提取公共函数

### 修复优先级

1. 先修复严重问题。
2. 再修复中等问题。
3. 轻微问题可按团队规范决定是否处理。
````
