# Rust 专项审核规则

| 检查项 | 描述                                         | 严重程度 |
| ------ | -------------------------------------------- | -------- |
| R01    | 使用 `unwrap()` 或 `expect()` 在非测试代码中 | 严重     |
| R02    | 未处理的 `Result` 或 `Option`                | 严重     |
| R03    | 不必要的 `clone()` 调用                      | 中等     |
| R04    | 未检查状态码就继续处理                       | 中等     |
| R05    | 错误统计缺失：失败路径未记录统计数据         | 中等     |
| R06    | 重试逻辑中计数器顺序错误                     | 中等     |
| R07    | 未使用的变量或导入                           | 轻微     |
| R08    | 未处理的异步错误                             | 中等     |
