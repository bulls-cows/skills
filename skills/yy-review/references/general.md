# 通用审核规则

## 审核维度

| 维度 ID | 检查内容                                                                      | 严重程度 |
| ------- | ----------------------------------------------------------------------------- | -------- |
| D01     | 语法与类型错误：语法结构错误、未定义变量、明显类型不匹配、未闭合标签或括号    | 严重     |
| D02     | 运行时逻辑错误：空指针、数组越界、错误分支、状态更新顺序错误、异步竞态        | 严重     |
| D03     | 安全风险：XSS、SQL 注入、命令注入、路径穿越、敏感信息泄露、不安全反序列化     | 严重     |
| D04     | 数据一致性与边界处理：空值、异常输入、分页边界、时间边界、并发更新冲突        | 中等     |
| D05     | 错误处理与异步流程：Promise 未处理、异常吞掉、加载状态未复位、重复请求风险    | 中等     |
| D06     | 可维护性与最佳实践：重复代码、复杂条件、无意义命名、死代码、过度封装          | 中等     |
| D07     | 调试代码与低风险风格问题：`console.log`、`debugger`、临时注释、格式轻微不一致 | 轻微     |

## 最佳实践规则

| 规则 ID | 描述                                       | 严重程度 |
| ------- | ------------------------------------------ | -------- |
| P01     | Early return：优先使用提前返回避免深层嵌套 | 中等     |
