# yy-check-skill-compliance

## 描述

扫描 `skills/` 和 `skills-internal/` 目录下的所有技能，依据 `skills/yy-create-skill` 的验收清单逐项检查合规性，输出不符合项列表供用户确认修复。

## 使用场景

- 需要批量验证所有技能是否符合规范
- 技能创建或更新后进行验收检查
- 定期检查技能目录的合规性

不应触发：

- 只是查看某个技能内容
- 创建或更新技能（应使用 `yy-create-skill`）
- 检查非技能目录的文件

## 指令

### 步骤 1. 扫描技能目录

遍历 `skills/` 和 `skills-internal/` 目录，收集所有包含 `SKILL.md` 的技能目录：

**决策分支**：

- **目录存在且包含 SKILL.md**：记录为待检查技能
- **目录存在但无 SKILL.md**：记录为结构异常（缺少必需文件）
- **目录不存在**：跳过

### 步骤 2. 读取检查标准

读取 `skills/yy-create-skill/SKILL.md` 的验收清单作为检查标准来源：

- 读取 `## 指令` 中 `### 步骤 7. 验收` 的检查项
- 读取 `resources/skill-guide.md` 的验收清单补充细节
- **不将检查项复制到本技能**，始终以 `yy-create-skill` 为权威来源

### 步骤 3. 逐项检查

对每个技能目录，按步骤 2 读取的验收清单逐项检查。

**记录规则**：

- 通过项：不记录
- 不通过项：记录技能名称、检查项、具体问题描述

### 步骤 4. 输出检查结果

```markdown
## 检查结果

### 扫描统计

- skills/ 目录下技能数量: [数量]
- skills-internal/ 目录下技能数量: [数量]
- 检查通过: [数量] 个
- 存在问题: [数量] 个

### 问题清单

| 技能名称 | 检查项   | 问题描述   |
| -------- | -------- | ---------- |
| [技能名] | [验收项] | [具体问题] |

### 修复建议

请确认需要修复的问题（回复编号，多个用逗号分隔）：

1. [技能名称] - [问题摘要]
2. [技能名称] - [问题摘要]
   ...
3. 暂不修复
```

### 步骤 5. 执行修复

根据用户确认的问题列表，调用 `yy-create-skill` 技能修复对应技能：

**决策分支**：

- **用户选择修复**：对选中的技能逐个调用 `yy-create-skill` 进行修复
- **用户选择暂不修复**：结束流程
- **用户未回复**：等待确认，不自动执行

## 注意事项

- 检查标准以 `skills/yy-create-skill` 为权威来源，不复制检查项到本技能
- 修复操作通过调用 `yy-create-skill` 技能完成，不直接修改技能文件
- 只检查 `skills/` 和 `skills-internal/` 目录下的技能
