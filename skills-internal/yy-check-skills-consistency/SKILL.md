# yy-check-skills-consistency

检查 README.md 中的技能列表与实际 skills/ 目录内容的一致性。

## 何时使用

当需要验证 README.md 中的技能列表是否符合以下条件时使用：

- 技能列表按字母顺序排序
- 技能列表与 skills/ 目录实际内容一致
- 需要修复发现的不一致问题

## 不应使用的情况

- 当只是查看 README.md 内容时
- 当只是检查 skills/ 目录内容时
- 当不是技能相关的文档一致性检查时

## 执行步骤

1. **读取 README.md**
   - 读取项目根目录的 README.md 文件
   - 提取技能列表部分的内容

2. **读取 skills/ 目录**
   - 列出 skills/ 目录下的所有子目录
   - 过滤出有效的技能目录（包含 SKILL.md 的目录）

3. **验证字母顺序排序**
   - 检查 README.md 中的技能列表是否按字母顺序排序
   - 如果未排序，记录需要调整的顺序

4. **验证内容一致性**
   - 比较 README.md 中的技能列表与 skills/ 目录中的实际技能
   - 识别出只在 README.md 中存在的技能（冗余项）
   - 识别出只在 skills/ 目录中存在的技能（缺失项）

5. **生成验证报告**
   - 输出排序检查结果
   - 输出内容一致性检查结果
   - 列出发现的所有问题

6. **修复问题**（可选）
   - 如果发现排序问题，按字母和其他重新排列技能列表
   - 如果发现缺失项，在 README.md 中添加相应的技能条目
   - 如果发现冗余项，从 README.md 中删除对应的技能条目

## 输出格式

```markdown
## 验证结果

### 排序检查

- 状态: ✅ 通过 / ❌ 未通过
- 详情: [具体说明]

### 内容一致性检查

- 状态: ✅ 通过 / ❌ 未通过
- 缺失项: [技能列表]
- 冗余项: [技能列表]

### 修复操作

- [已执行 / 未执行] 修复操作
- 详情: [具体修复内容]
```

## 示例

### 输入

```text
检查 README.md 中的技能列表是否与 skills/ 目录一致
```

### 输出

```markdown
## 验证结果

### 排序检查

- 状态: ✅ 通过
- 详情: 技能列表已按字母顺序排序

### 内容一致性检查

- 状态: ❌ 未通过
- 缺失项: yy-new-feature
- 冗余项: yy-deprecated-feature

### 修复操作

- 已执行 修复操作
- 详情: 已添加 yy-new-feature，已删除 yy-deprecated-feature
```
