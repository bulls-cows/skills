# yy-check-skills-consistency

## 描述

检查 README.md 中的技能列表与实际 skills/ 目录内容的一致性，验证排序和内容是否匹配，并修复发现的问题。

## 使用场景

- 需要验证 README.md 中的技能列表是否按字母顺序排序
- 需要验证技能列表与 skills/ 目录实际内容一致
- 需要修复技能列表的不一致问题

不应触发：

- 只是查看 README.md 内容
- 只是检查 skills/ 目录内容
- 不是技能相关的文档一致性检查

## 指令

### 步骤 1. 读取 README.md

- 读取项目根目录的 README.md 文件
- 提取技能列表部分的内容

### 步骤 2. 读取 skills/ 目录

- 列出 skills/ 目录下的所有子目录
- 过滤出有效的技能目录（包含 SKILL.md 的目录）

### 步骤 3. 验证字母顺序排序

- 检查 README.md 中的技能列表是否按字母顺序排序
- 如果未排序，记录需要调整的顺序

### 步骤 4. 验证内容一致性

- 比较 README.md 中的技能列表与 skills/ 目录中的实际技能
- 识别出只在 README.md 中存在的技能（冗余项）
- 识别出只在 skills/ 目录中存在的技能（缺失项）

### 步骤 5. 生成验证报告

- 输出排序检查结果
- 输出内容一致性检查结果
- 列出发现的所有问题

### 步骤 6. 修复问题

**决策分支**：

- **发现排序问题**：按字母顺序重新排列技能列表
- **发现缺失项**：在 README.md 中添加相应的技能条目
- **发现冗余项**：从 README.md 中删除对应的技能条目
- **无问题**：跳过修复

### 步骤 7. 输出结果

```markdown
## 验证结果

### 排序检查

- 状态: ✅ 通过 / ❌ 未通过
- 详情: [具体说明]

### 内容一致性检查

- 状态: ✅ 通过 / ❌ 未通过
- 缺失项: [技能列表]
- 冗余项: [技能列表]

### 修复操作

- [已执行 / 未执行] 修复操作
- 详情: [具体修复内容]
```
